# Rital — The Princess Story

فيلم عيد ميلاد تفاعلي من ثمانية فصول، يعمل دون حزم أو خادم خارجي.

## التشغيل

```bash
cd rital-princess-film
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح: `http://localhost:8000`

ابدأ الفيلم بزر «ابدئي الحكاية» لتفعيل الموسيقى التفاعلية. يمكنك استخدام السهمين، السحب على الهاتف، أو مفاتيح الأسهم للتنقل.

## المحتوى

- واجهة عربية متجاوبة بثمانية مشاهد: البوابة، الدخول، الاستقبال، سكر، القاعة، التتويج، الرسالة، والختام.
- حركة بوابة وتاج، ورود متحركة، ألعاب نارية، تفاعل لمس ولوحة مفاتيح.
- مقطوعة نغمية أصلية مولّدة محلياً عبر Web Audio API؛ لا تستخدم ملفات موسيقى محمية.
